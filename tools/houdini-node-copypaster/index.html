De una red a otra.

Dos botones en una pestaña: Parsec Nodes v2.1. Así de corto es el recorrido.

  1. 01

    Selecciona y copia

    Selecciona una cadena de nodos en una sola red y pulsa Copy Nodes en la shelf.

  2. 02

    Cambia de equipo

    Entra en Parsec y deja un momento para que se sincronice el portapapeles de texto.

  3. 03

    Pega y continúa

    Abre una red del mismo tipo en el destino y pulsa Paste Nodes. También funciona entre redes locales.

Instálalo una vez. En cada equipo.

Descarga y extrae el ZIP. En Houdini, abre Windows → Python Shell y ejecuta el comando de tu sistema, ajustando la ruta al instalador.

Linux

Sustituye /ruta/ por la carpeta donde hayas extraído la herramienta.

PYTHON SHELL
exec(open('/ruta/install_parsec_nodes.py', encoding='utf-8').read())

Windows

Sustituye C:\ruta\ por la ubicación real del instalador.

PYTHON SHELL
exec(open(r'C:\ruta\install_parsec_nodes.py', encoding='utf-8').read())

No necesitas reiniciar Houdini ni instalar paquetes Python. Si la pestaña no aparece, usa el + de las shelves → Shelves → Parsec Nodes v2.1.

¿Prefieres instalarlo directamente por Parsec?

Copia la línea de instalación en este equipo, pégala en la Python Shell del Houdini remoto y pulsa Enter. Guarda los botones en las preferencias de ese Houdini.

También puedes descargar la línea como archivo de texto, abrirla y copiarla completa.

Qué viaja con tus nodos.

Dentro de la copia

  • Cadenas de nodos estándar de Houdini.
  • Parámetros, conexiones y código VEX.
  • Expresiones, rampas y parámetros personalizados.
  • Claves numéricas y de texto, interpolación y tangentes.
  • Ciclos, extrapolación y claves en subframes.

A tener en cuenta

  • Los tipos y parámetros deben existir en el destino.
  • Los tiempos de las claves se conservan en segundos, también con FPS distintos.
  • Los HDAs externos, las subredes editadas y la geometría bloqueada quedan fuera.
  • Las texturas, cachés, notas y cajas no se transportan.
  • Las referencias externas pueden necesitar ajustes.

La red se reconstruye con la API de Houdini. La herramienta no convierte licencias de contenido ni elimina restricciones de archivos o HDAs externos. Probada en Houdini Apprentice 22.0.466 en Linux; la comprobación de la sesión comercial de FX en Windows sigue pendiente.

Para usar atajos: mantén Ctrl + Alt + Shift y haz clic en cada botón de la shelf. Puedes asignar Ctrl + Shift + C y Ctrl + Shift + V, revisando posibles conflictos.
