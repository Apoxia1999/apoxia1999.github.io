Houdini Node Copypaster

Copia nodos, parámetros y animación entre equipos por Parsec.

Descargar ZIP ↓

Instalación y uso

  1. En ambos Houdini: abre Windows → Python Shell, pega el instalador y pulsa Enter.
  2. Selecciona los nodos y pulsa Copy Nodes en la pestaña Parsec Nodes v2.1.
  3. En el otro equipo, abre una red del mismo tipo y pulsa Paste Nodes.

Activa el portapapeles de texto compartido de Parsec. También funciona entre redes locales.

Instalación manual

Extrae el ZIP y ejecuta esto en la Python Shell, cambiando la ruta:

exec(open(r'RUTA/install_parsec_nodes.py', encoding='utf-8').read())

Si no aparece la pestaña: + de las shelves → Shelves → Parsec Nodes v2.1.
