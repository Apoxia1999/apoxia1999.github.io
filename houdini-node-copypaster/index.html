Houdini Node Copypaster

Copia nodos, parámetros y animación entre equipos por Parsec.

Descargar ZIP ↓

La v2.2 es una versión de seguridad: actualiza los dos equipos. Las versiones anteriores podían ejecutar código al pegar un portapapeles manipulado.

SHA-256 del ZIP: ff19e80314185e1099a6ff6a719f4606c36d5b45b613b4ea747113ca7d4f89ae. Compruébalo antes de instalar; huellas de las tres descargas en SHA256SUMS.

Instalación y uso

  1. En ambos Houdini: extrae el ZIP, abre Windows → Python Shell y ejecuta el instalador con el comando de abajo.
  2. Selecciona los nodos y pulsa Copy Nodes en la pestaña Parsec Nodes v2.2.
  3. En el otro equipo, abre una red del mismo tipo y pulsa Paste Nodes.

Cambia la ruta por la carpeta donde extrajiste el ZIP:

exec(open(r'RUTA/install_parsec_nodes.py', encoding='utf-8').read())

Si no aparece la pestaña: + de las shelves → Shelves → Parsec Nodes v2.2.

Activa el portapapeles de texto compartido de Parsec. También funciona entre redes locales.

Alternativa: instalar por el portapapeles

Solo si no puedes copiar archivos al otro equipo. Es el mismo instalador comprimido en una línea: no se puede leer a simple vista, así que úsalo solo desde esta página.
